Getting Started

Set up and start monitoring your 5G network slices

1. Overview 2. Prerequisites 3. First Launch 4. Add Slices 5. Collect Metrics 6. AI Analysis 7. Next Steps
1

What Is This App?

The 5G Network Slice Performance Monitor tracks and analyzes performance metrics for 5G network slices. It monitors latency, throughput, packet loss, and jitter against configurable SLA targets. An integrated AI agent provides health assessments and actionable recommendations.

Supported slice types:

  • eMBB — Enhanced Mobile Broadband (high throughput for video, AR/VR)
  • URLLC — Ultra-Reliable Low-Latency Communications (factory automation, remote surgery)
  • mMTC — Massive Machine-Type Communications (IoT sensors, smart grids)
2

Prerequisites

  • Docker and Docker Compose (for containerized deployment)
  • Python 3.11+ (for local development)
  • (Optional) A Kindo API key and agent ID for AI-powered analysis
3

First Launch

Using Docker:

docker compose up --build

For local development:

pip install -r requirements.txt
python -m flask --app wsgi:app run --port 8000

Open http://localhost:8000 in your browser. The app will seed three sample network slices on first launch.

4

Add Network Slices

Navigate to Slices and use the form at the bottom to add a new slice. Set SLA targets for latency (ms), throughput (Mbps), and availability (%). Or use the REST API:

curl -X POST http://localhost:8000/api/slices \
  -H "Content-Type: application/json" \
  -d '{"name":"eMBB Downtown","type":"eMBB","sla_latency_ms":15,"sla_throughput_mbps":200}'
5

Collect Metrics

Submit performance measurements through the slice detail page or via the API:

curl -X POST http://localhost:8000/api/metrics \
  -H "Content-Type: application/json" \
  -d '{"slice_id":"slice-embb-001","latency_ms":12.5,"throughput_mbps":95,"packet_loss_pct":0.02}'

The dashboard will update automatically to show SLA compliance status.

6

AI-Powered Analysis

Click Analyze on any slice card or detail page to get a health score and recommendations. The analysis works out of the box with a local heuristic engine. For more advanced analysis, configure the Kindo AI agent:

  1. Set KINDO_API_KEY in your environment
  2. Set KINDO_SLICE_PERFORMANCE_AGENT_ID to your deployed agent ID

See the agent/ directory for agent configuration files.

7

Next Steps

  • Configure alerting thresholds per slice type
  • Review the Analytics page for trend analysis
